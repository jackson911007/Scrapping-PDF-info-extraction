* This is the code to do pdf information extraction using Google Gemini. I named this AI agent Jacky. I will continue to update new version to this Github repo <br>

* This code is separated to two main parts:
(1) Read in pdf file --> sparse the text and extract the text from table ---> combine all the table and contect information <br>
(2) Apply Gemini to digest the text message. To do so, you need to define clear message (prompt) to Gemini and design the output <br>

* This code outputs a csv file that collects the information extracted from pdf based on user-defined prompt <br>
